# TRB rec Store — Flatsome Child

Repository privato del child theme attivo su `store.trbrec.com`.

## Contenuto

- copia versionata dei file PHP e CSS del child theme;
- design system 2026 in `assets/css/trb-global-style.css`;
- immagini e asset proprietari in `assets/images`;
- deploy WordPress gestito tramite Deployer for Git.

Il design system resta separato dal foglio principale finché le singole modifiche non sono state verificate e promosse nel tema attivo.
